JobPilot · System architecture · v0.1 · 13 Nov 2026

Run a multi-user job-hunt agent for $0 a month

The server only stores data and runs a light schedule. The two costly jobs, filling application forms and calling an LLM, happen on resources each user already has: their own browser and their own API key.

$0 / month hosting Online, any device Multi-user from day one “Ask me first” by default No LinkedIn / Indeed

Three choices that keep it free

Browser extension submits

The user's browser fills the forms

Running headless browsers on a server is the costliest part of this kind of app, and job sites block data-center IPs. A JobPilot browser extension fills and submits forms from the user's own Chrome, on their home connection and with their own sign-ins. Each new user brings their own compute.

Bring your own key

Each user brings their own LLM key

Scoring, tailoring and drafting answers run on a key the user pastes in Settings. The key is stored encrypted. A Gemini free-tier key costs the user nothing, and any paid key also works. JobPilot never pays for tokens.

Shared catalog

Fetch each job board once

Greenhouse, Lever and Ashby publish free JSON job feeds. Each company board is fetched once per run, however many users there are. Matching is then done per user against that one shared job table.

The schedule runs on GitHub Actions, not Vercel. Vercel Hobby cron jobs can run only once a day, and each scheduled run also keeps the free Supabase project from pausing.

One job, start to finish

  1. Discover. The scheduled worker fetches the shared list of company boards and upserts the jobs into a shared jobs table, deduplicated by a hash of company, title and location. A user can also paste a link, which goes through the same parser.GitHub Actions · Next.js API for pasted links
  2. Filter without an LLM. SQL drops jobs that don't fit each user's preferences: titles, locations, excluded companies, already applied. This costs nothing and leaves a short list for each user.Postgres
  3. Score. Using the user's own key, the LLM returns a 0–100 score plus the requirements met and the gaps. A daily cap per user (for example 30 scores) keeps it inside a free-tier quota.GitHub Actions → user's LLM
  4. Tailor and validate. Jobs above the threshold get a tailored resume and cover letter, stored as structured JSON. A rule-based validator checks that every employer, title, date, skill and metric appears in the master profile. If any claim fails, the draft is regenerated.GitHub Actions or Next.js API (Tailor now)
  5. Classify the form. Greenhouse's public API lists each posting's application questions, so many forms can be classified on the server. For other sites, the extension inspects the page when it opens the link. Forms with screening questions, surveys, assessments, sign-ups or a CAPTCHA go to Needs you.Worker for Greenhouse · extension for the rest
  6. Review. The user approves, edits or skips on the Review screen. Approving adds a submission task to the queue.Next.js · Postgres task queue
  7. Submit. The extension picks up approved tasks while the browser is open. It respects the daily cap and a per-site throttle, fills the form, attaches PDFs rendered in the browser, submits, and uploads a screenshot. The status changes to Applied.Extension → company site · Storage
  8. Track. Status changes are written to status_events. A follow-up reminder appears 7 days after Applied if there's no response. The daily digest email lists new matches and items in Needs you.Postgres · Resend

How users are kept apart

  • Every user-owned table has a user_id column, with row-level security set to user_id = auth.uid().
  • boards and jobs are a shared catalog that users can read but not write. Only the worker writes to them.
  • The extension signs in with the user's Supabase session, so it can only see that user's tasks.
  • Only the worker holds the service-role key, as a GitHub secret. The browser never sees it.

Rough capacity on free tiers

  • Shared jobs: 5,000 postings × about 8 KB ≈ 40 MB
  • Per user, after 300 applications with documents stored as JSON (about 5 KB): ≈ 2 MB
  • Screenshots: compressed JPEG of about 60 KB, kept for 30 days
  • That puts the ceiling at roughly 100–150 active users before the 500 MB database or 1 GB of file storage fills up.
  • The first paid step after that is Supabase Pro at $25/mo. Nothing else needs to change.

Risks and mitigations

RiskImpactMitigation
Auto-submit only runs while the browser is openMediumThis fits the default “Ask me first” mode: the user approves, then the queue drains next time Chrome is open. A server-side Playwright worker can be added later if needed.
Job sites change their forms or add bot checksMediumWrite a field-mapping adapter for each ATS (Greenhouse, Lever, Ashby first). If a form can't be classified, send it to Needs you. Never try to solve a CAPTCHA.
Resumes sent to a free LLM tier are used for trainingHigh (privacy)Show a clear warning when the user adds their key, recommend a paid key, and send the LLM only the profile fields it needs.
Free tiers change without noticeMediumOracle halved its free ARM allowance in 2026, which is why this design doesn't depend on it. Keep everything portable: plain Postgres, a plain Node worker, standard Next.js.
The LLM invents experienceHighA rule-based validator checks every claim against the profile JSON before the user sees it, and the Review screen shows a diff against the master resume.
A leaked API keyHighStore keys in Supabase Vault, decrypt them only in the worker or the API route, and never return them to the browser or write them to logs.

Decisions to confirm

Extension store

Recommended: sideload for now and publish on Firefox Add-ons (free). Pay Chrome's one-time $5 fee only when outside users join.

Default LLM provider

Recommended: let users pick any provider and suggest Gemini's free tier, with the privacy warning.

Commercial plans

Recommended: keep it free and non-commercial so Vercel Hobby is allowed. If you'll charge later, start on Cloudflare Workers instead.

Which company boards to seed

Recommended: start with about 200 boards that match your target roles, and let users add boards.
